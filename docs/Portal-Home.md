# Documentation Portal

## Start by role

| Role | Recommended path |
|---|---|
| Executive leader | Framework overview → Governance Model → KPI Catalogue → Dashboard Gallery |
| PMO or portfolio leader | Metrics Library → KPI Catalogue → Dashboard Specification Standard → Roadmap |
| Program manager | Transformation Framework → Consolidation Playbook → Migration and cutover runbooks |
| Jira platform owner | Governance Model → Enterprise Reference Architecture → Repository Standards |
| Service-management leader | KPI Catalogue → JSM dashboard concepts → SLA and operations guidance |
| Power BI developer | Power BI Implementation Guide → KPI Catalogue → Technical Libraries |
| Engineer or analyst | JQL Library → Technical Libraries → Synthetic Dataset Standard |
| Contributor | Contributing Guide → Documentation Standards → Data Policy → Security Policy |
