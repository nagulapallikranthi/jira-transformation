# Executive Arrival Experience

This file implements the Executive Arrival Experience ("Engineering Command Center").

Commit A focuses on answering the single executive question immediately: "Is engineering healthy?". The top-left card and hero provide that answer without scrolling.

Design rules enforced here:

- Executive-first: first screen answers the primary decision question.
- No raw numbers for top-line KPI cards; they show decisions and actions.
- Components are referenced and populated by a client-side loader (commit B).
