# Reusable Templates

This folder will contain editable, organization-neutral templates for Jira transformation, governance, migration, analytics, and operational readiness.

## Planned template groups

- current-state assessment;
- configuration inventory;
- dependency and integration register;
- governance charter and decision-rights matrix;
- migration wave plan;
- readiness, cutover, rollback, and hypercare checklists;
- KPI definition and dashboard specification;
- risk, issue, decision, and action registers;
- data-quality and reconciliation checklist;
- executive status and steering-committee packs.

## Template quality standard

Each template must identify its purpose, owner, required inputs, completion guidance, approval point, output, and retention or review cadence. Sample rows must use fictional data only.
