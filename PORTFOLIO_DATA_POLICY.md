# Portfolio Data Policy

## Zero-organization-data requirement

Every artifact in this repository must be generic, fictional, reusable, and free of organizational data.

## Prohibited content

Do not add:

- Employer, customer, vendor, employee, team, product, service, or leadership names
- Real Jira URLs, project keys, issue IDs, board IDs, sprint names, field IDs, workflow IDs, automation IDs, or app identifiers
- Real users, groups, email addresses, tenant IDs, endpoints, credentials, tokens, secrets, or webhook URLs
- Internal incidents, vulnerabilities, architecture, infrastructure, release plans, or security controls
- Actual ticket volumes, SLA values, financial data, cost savings, staffing levels, or performance results
- Workplace screenshots, Jira exports, logs, reports, or copied internal documents

## Required standard

- Use fictional names and synthetic data only
- Label all sample numbers as illustrative or demonstration-only
- Build reusable templates rather than reproducing internal documents
- Review hidden spreadsheet sheets, comments, formulas, links, document properties, and image metadata before publication
- Review Git history for previously committed sensitive information

## Fictional reference environment

- Organization: Northstar Digital
- Jira projects: OPS, ENG, SVC
- Teams: Platform Operations, Reliability, Developer Experience
- Products: Product Alpha, Product Beta
- Users: Alex Morgan, Priya Shah, Jordan Lee

All names above are fictional.
