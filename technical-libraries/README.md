# Technical Libraries

This area organizes reusable implementation examples that translate the framework into working analytics and automation patterns.

## Planned libraries

- `jql/` — issue selection, cohort definitions, governance checks, and operational queues
- `sql/` — normalized analytics models, history, snapshots, and reconciliation
- `mdx/` — EazyBI measures, time windows, realized-versus-pipeline logic, and trend calculations
- `dax/` — Power BI measures, targets, RAG states, and executive narratives
- `rest-api/` — authenticated extraction patterns, pagination, rate limits, retries, and write-back controls
- `automation/` — Jira automation patterns, guardrails, idempotency, and audit logging
- `python/` — validation, transformation, synthetic-data generation, and quality checks

## Example standard

Every example must include:

1. business purpose;
2. assumptions and prerequisites;
3. complete example using placeholders;
4. expected output;
5. performance, security, and scale considerations;
6. validation and failure scenarios;
7. related dashboard or metric.

Examples must never contain live URLs, credentials, field IDs, project keys, personal information, or copied organizational data.
